# 4YP_Benjamin_Drinkwater
## 'How much resolution is enough?' Evaluating Spatial Clustering Methods for Efficient Multi-Vector Energy System Optimisation

The code is split into two directories, the clustering framework applied to Ukraine, and subsequently applied to La Araucania. 
The timeseries pull and model setup are part of the DETECCO framework. 

The clustering notebooks follow the order of the general methodology:

1. Data Extraction
2. Feature Construction
3. Clustering
4. Network Construction
5. DETECCO Optimisation
6. Analysis
